# 🌌 Віз-Атлас: Децентралізований космічний атлас 🚀

Удосконалений, готовий до використання інтерактивний 3D-космічний атлас, побудований на основі наукових API (NASA, SIMBAD TAP) та інтегрований з локальними блокчейн-мережами (Polygon Mainnet) для збереження перевірених астрономічних відкриттів.

**Активний додаток:** [vizatlas.space](https://vizatlas.space)  
**Блокчейн-адреса контракту:** [`0x013164EA0570675650051FA302992f64c5c258d9`](https://polygonscan.com/address/0x013164EA0570675650051FA302992f64c5c258d9)
